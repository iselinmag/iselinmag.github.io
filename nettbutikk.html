Frontend · HTML & CSS

Nettbutikk

A responsive three-page web shop built from sketches with only HTML and CSS: a front page, a product page and a checkout. Written by hand, without frameworks.

  • Team Individual exam
  • Course Web Development (ITF10511), Østfold University College
  • When Autumn 2024

The assignment

Build index.html, product.html and checkout.html to match the sketches, with one shared stylesheet. The rules were strict, which forced clean, semantic markup.

  • Validated HTML without errors
  • Max 5 <div> tags per page (I used 2–4)
  • Semantic tags: header, nav, main, section, article, aside
  • Identical menu and footer on every page
  • Both CSS Flexbox and Grid
  • Media queries, built mobile first
  • One stylesheet for the whole site
  • WCAG checklist for accessibility

The pages

How it is built

HTML

  • Semantic structure instead of divs
  • Same header and footer copied to all three pages
  • Anchor links from the menu to sections on the front page
  • Alt text on all images

CSS

  • Mobile first, with breakpoints at 600 and 1000 px
  • Grid for products, categories and the product page
  • Flexbox for menus, buttons and the review list
  • Horizontal scroll with scroll snap for reviews
  • Font Awesome icons

What I learned

  • Semantic HTML makes a page easier to style, read and use with a screen reader
  • Designing for mobile first gives simpler CSS than squeezing a desktop layout
  • When to choose Grid and when Flexbox

This portfolio is built the same way, with plain HTML and CSS.
